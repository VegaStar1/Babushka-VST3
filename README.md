# Babushka

VST3-эмуляция полумодульного аналогового синтезатора (прототип — Moog Grandmother, 2018).
Название, код и интерфейс собственные; имя и логотип Moog не используются.

**Статус:** ядро звука + арпеджиатор/секвенсор + внешний вход + патч-панель (41 точка, по мануалу Grandmother).
Финальный интерфейс (собственный дизайн) — следующий этап; сейчас временная функциональная панель со списком кабелей.

## Что реализовано

| Модуль | Прототип | Как смоделировано |
|---|---|---|
| Осциллятор 1 | Minimoog/Voyager VCO | 32'/16'/8'/4'; треугольник, пила, меандр 50 %, узкий импульс ≈16 % (замер SOS). PolyBLEP/BLAMP-антиалиасинг |
| Осциллятор 2 | то же | 16'/8'/4'/2'; ±7 полутонов; hard sync с субсэмпловой точностью (BLEP в момент сброса); узкий импульс ≈18 % |
| Микшер | CP3 | Общий суммирующий каскад с ограниченным запасом: мягкий перегруз примерно с 1 часа, громкий вход «давит» остальные, лёгкая асимметрия (2-я гармоника) |
| Фильтр | 904A ladder, 24 дБ/окт | Нелинейная транзисторная лестница (tanh в каждом каскаде и на входе), ZDF/TPT без единичной задержки, неявная система решается точно. Потеря баса при резонансе как у железа, самовозбуждение, KBD TRACK off / 1:2 / 1:1 |
| Огибающая | 911 | RC-экспоненты, атака с «перелётом» (convex), single trigger |
| VCA | 902 | Режимы ENV / KB RLS / DRONE, мягкая сатурация |
| Mod Osc | — | 0,07 Гц – 1,3 кГц; синус, пила, рампа, меандр; S/H шума; глубины PITCH/CUTOFF/PW, масштабируемые MOD wheel |
| Пружинный ревербератор | 905, 6" пружина | Две пружины: транзитная задержка + каскад «растянутых» аллпассов (дисперсия, чирпы) + модуляция задержки (ripple), драйвер с насыщением. MIX: 100 % dry → 100 % wet, как у оригинала |
| Контроллер | — | Pitch bend 1–12 полутонов, mod wheel (CC1), glide LCR/LCT/EXP, legato glide, приоритет нот Last/Low/High, сустейн-педаль |
| Арпеджиатор / секвенсор | — | ARP: ORDR / FWD-BKWD / RNDM, 1–3 октавы, HOLD (латч, новый аккорд после отпускания начинает новый паттерн). SEQ: 3 последовательности × 256 шагов (нота/пауза, tie, accent), транспонирование клавишей. REC: пошаговая запись с клавиатуры, кнопки TIE / REST / ACCENT. Темп 20–280 BPM, TAP, синхронизация с DAW (24 деления, как CC 90). Последовательности сохраняются в проекте |
| Патч-панель | 41 точка: 21 вход, 16 выходов, 4 параллельных Mult | Каждый модуль публикует выходы в вольтах; вход читает сумму подключённых кабелей или свой нормализованный источник (кабель в гнезде разрывает нормализацию). Без кабелей звук побитово совпадает с жёстко соединённым путём. Mult — один узел. Обратные связи работают с задержкой на 1 сэмпл. Шкалы: аудио ±5 В, CV 1 В/окт., Gate +8 В, огибающая 0…+8 В, KB OUT ±5 В, KB VEL 0…+5 В, клок 0…+5 В. Новые ручки: High Pass (ФВЧ 6 дБ/окт.), Attenuator (двуполярный, вход нормализован на +8 В) |
| Задние гнёзда ARP/SEQ | CLOCK IN / ON-OFF IN / RESET IN / CLOCK OUT | Clock-режим (PPQN) и Step-Advance, пуск/останов и сброс по напряжению > 2,5 В, выход клока 50 % |
| Внешний вход | INSTRUMENT IN | Боковой вход (sidechain) плагина → микшер → фильтр → VCA → пружина. Ручка Ext In Level (на железе регулировки нет) |
| Качество | — | Голос работает с передискретизацией 1×/2×/4× (Eco/Normal/High), выходной FIR-дециматор |

## Проверка (tools/render.cpp)

`babushka_render <папка>` пишет демо-WAV и печатает тесты:

- самовозбуждающийся фильтр при KBD TRACK 1:1 строит октавы с точностью ±0,3 цента;
- АЧХ лестницы: −12 дБ на частоте среза, потеря баса −13,6 дБ при 90 % резонанса;
- пружина: T60 по октавным полосам сверяется с записями железа (от ≈9 с на 60–240 Гц до ≈1–2 с на 4–8 кГц), уровень 100 % wet ≈ dry;
- патч-панель: перечень гнёзд (21 + 16 + 4), эквивалентность кабелей нормализованным путям, 1 В/окт. через Mult, ФВЧ, тремоло с LFO на VCA AMT IN, velocity → Cutoff, аттенюатор, уровни Gate/KB/VEL, LFO по клавиатуре, CLOCK OUT/IN, STEP-ADVANCE, RESET IN, fuzz со случайными кабелями;
- выходная AC-связь: «завал» плоской вершины меандра на 66 Гц ≈ 5,5 Гц эквивалента, как в записи;
- 60 с случайных патчей: без NaN/Inf, выход ограничен;
- арпеджиатор/секвенсор: порядок нот во всех режимах, длительность шага и гейта с точностью до сэмпла, tie, транспонирование, синхронизация с DAW;
- host-тест (`-DBABUSHKA_HOST_TEST=ON`): загрузка .vst3 как в DAW, MIDI, арпеджио, сохранение/загрузка состояния и последовательностей, внешний вход;
- CPU: ≈5 % одного ядра при 2×, ≈8,5 % при 4× (48 кГц, Linux x86-64, -O2).

## Сборка

Нужны CMake ≥ 3.22 и компилятор C++17. JUCE 8.0.4 скачивается автоматически (или `-DJUCE_DIR=...`).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --target Babushka_VST3
```

GitHub Actions (`.github/workflows/build.yml`) собирает VST3 под Windows x64 и macOS (Universal) и выкладывает артефакты.

## Что калибровать (данных в открытых источниках нет)

Помечены в коде как `ASSUMPTION`:
- диапазоны времён ADSR (сейчас 1–2 мс … 10 с) и glide (2 мс … 5 с);
- максимальные глубины Mod Osc (pitch ±2 окт., cutoff ±5 окт.) и Envelope Amt (±6 окт.);
- кривая перегруза микшера и входной уровень фильтра;
- параметры пружины: затухание по частоте откалибровано по записям (`docs/analysis/hardware-recordings.md`), остальное (длины, дисперсия, АЧХ бака, начальная «гулкость») — по-прежнему предположения;
- арпеджиатор: длина гейта 50 %, шаг свободного темпа 1/8 (в мануале не указано). ACCENT даёт огибающую на KB VEL OUT (релиз ≈60 мс — предположение), при выключенном секвенсоре там уровень velocity;
- патч-панель: глубина Lin FM (100 Гц/В), влияние PWM IN (0…+5 В → до +0,45 скважности), 0 В на KB OUT = до первой октавы (нота 60), KB OUT показывает pitch с glide, Env Amt In (±5 В = ±1 по ручке), диапазон ручки High Pass (16 Гц … 8 кГц), масштаб S/H OUT, пороги триггеров 1,2 В / 2,5 В из мануала.

## Патч-панель: чего ещё нет

- Eurorack Out и Reverb Out пока доступны только как источники для кабелей внутри плагина (отдельных выходных шин нет).
- Global Settings KB OUT range (−5…+5 / 0…10 В) и Local On/Off не реализованы.
- Входы с тактом/гейтом читаются раз в сэмпл хоста; при Clock In внешний клок быстрее шага (PPQN × шаг) даёт не более одного шага на фронт.

## Внешний вход в DAW

Ableton Live: в плагине Babushka откройте секцию Sidechain и выберите дорожку-источник.
Cubase: включите боковую цепь (sidechain) у инструмента и отправьте на неё сигнал с нужной дорожки.
Чтобы слышать внешний звук без нажатия клавиш, поставьте VCA Mode = DRONE.

Лучший способ — записи с настоящего Grandmother: свипы, импульс в реверб, ADSR на осциллографе.
