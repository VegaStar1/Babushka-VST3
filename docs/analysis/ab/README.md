# A/B-записи изменений звука

Моно, 48 кГц, 16 бит. `*_before.wav` — до шага, `*_after.wav` — после.
Файлы `ab_bass`, `ab_lead`, `ab_pad` выровнены по RMS (слышна разница тембра, а не громкости);
`ab_note_then_selfosc` и `preset_*` не нормализованы (громкость как в плагине). Источник: `babushka_render <папка> ab`
и `babushka_presetaudit --wav <папка>`.

## step1-ladder: горячий вход ладдера (kLadderDrive 0,6 → 2,0) и смещение входной пары 0,03

Пила / треугольник 110 Гц, Resonance 0, микшер 100 %: H1 относительно усиления микшера и H2 относительно H1.

| | до | после |
|---|---|---|
| пила, срез 400 Гц: H1 | −4,1 дБ | −5,9 дБ |
| треугольник, срез 400 Гц: H1 | −3,0 дБ | −5,2 дБ |
| треугольник, фильтр открыт: H2 | −26,6 дБ | −21,4 дБ |
| треугольник, срез 400 Гц: H2 | −31,2 дБ | −30,3 дБ |
| самовозбуждение относительно ноты пилой (`ab_note_then_selfosc`) | −2,8 дБ | −12,0 дБ |

При открытом фильтре ладдер в полосе пропускания почти прозрачен (tanh входа и ступеней компенсируют друг друга),
насыщение слышно на закрытом и среднем срезе. Самовозбуждение тише в 1/kLadderDrive раз — это свойство модели.
