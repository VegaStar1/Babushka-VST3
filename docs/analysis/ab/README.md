# A/B-записи изменений звука

Моно, 48 кГц, 16 бит. `*_before.wav` — до шага, `*_after.wav` — после.
Файлы `ab_bass`, `ab_lead`, `ab_pad` выровнены по RMS (слышна разница тембра, а не громкости);
`ab_note_then_selfosc` и `preset_*` не нормализованы (громкость как в плагине). Источник: `babushka_render <папка> ab`
и `babushka_presetaudit --wav <папка>`.

## step1-ladder: горячий вход ладдера (kLadderDrive 0,6 → 2,0) и смещение входной пары 0,03

Пила / треугольник 110 Гц, Resonance 0, микшер 100 %: H1 относительно усиления микшера и H2 относительно H1.

| | до | после |
|---|---|---|
| пила, срез 400 Гц: H1 | −4,1 дБ | −5,9 дБ |
| треугольник, срез 400 Гц: H1 | −3,0 дБ | −5,2 дБ |
| треугольник, фильтр открыт: H2 | −26,6 дБ | −21,4 дБ |
| треугольник, срез 400 Гц: H2 | −31,2 дБ | −30,3 дБ |
| самовозбуждение относительно ноты пилой (`ab_note_then_selfosc`) | −2,8 дБ | −12,0 дБ |

При открытом фильтре ладдер в полосе пропускания почти прозрачен (tanh входа и ступеней компенсируют друг друга),

## step2-cv-thump: CV-протечка ладдера и VCA («тук»)

`before` здесь — состояние после step1. Протечка огибающей среза в аудио (0,0006 на октаву свипа через ФВЧ 20 Гц) и
смещение на выходе VCA (0,004 × усиление); обе проходят выходную AC-связь. Все три числа — ASSUMPTION.

| Замер (`babushka_render`, «CV feedthrough») | значение |
|---|---|
| пик «тука» при микшере в нуле, Env Amt макс., короткий Decay | −33,8 дБ от полной ноты |
| переброс знака после гейта | есть |
| возврат к 10 % пика после гейта | 101 мс (железо: 0,1–0,4 с) |
| та же огибающая, Attack 0,5 / Decay 0,6 | −48,5 дБ от полной ноты (щелчка нет) |

`test_cv_thump_*` — только протечка, микшер в нуле; `test_cv_thump_after_plus26dB.wav` — то же, громче на 26 дБ, чтобы услышать форму.
Громкость пресетов не изменилась (±0,2 дБ, медиана 0,0 дБ).

## step5-note-spread: разброс от ноты к ноте (Analog Drift)

`before` — состояние после step2. На каждую ноту случайный сдвиг: строй каждого VCO ±1,5 цента, ширина импульса ±0,01,
времена Attack / Decay / Release ±3 %, срез ±0,005 окт; это значения при Analog Drift = 0,25 (по умолчанию), при 1,0 втрое больше,
при 0 звук побитово как раньше (проверено сравнением выходов). Медленный дрейф строя не менялся. Все диапазоны — ASSUMPTION.

Срез взят в 10 раз меньше плана (±0,05 окт): при самовозбуждённом фильтре на KBD TRACK 1:1 это ошибка высоты,
±0,05 окт давало «свисту» ±60 центов мимо ноты (замер: 256…270 Гц вместо 261,6 Гц).

| Замер (`babushka_render`, «Note-to-note spread»: 8 одинаковых нот A4, пила) | разброс высоты |
|---|---|
| Analog Drift 0 | 0,01 цента |
| Analog Drift 0,25 | 3,0 цента (−1,2 … +1,9) |
| Analog Drift 1,0 | 9,4 цента (−3,2 … +6,2) |

`ab_repeat` — одна и та же нота баса 16 раз.
